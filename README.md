# AtCoder Statement Copier

앳코더 문제 페이지에 지문 복사 버튼을 추가하는 Chrome 확장입니다.
현재 표시된 언어의 지문, 제약, 입출력 설명과 예제를 일반 텍스트로 복사합니다.
변수와 수식은 LaTeX 원문을 `$...$` 또는 `$$...$$`로 감싸고, 예제의 줄바꿈과 들여쓰기를 보존합니다.

## 로컬 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누르고 이 폴더를 선택합니다.
4. 앳코더 문제 페이지를 새로고침하고 **Copy statement**를 누릅니다.
